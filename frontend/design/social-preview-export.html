Comment exporter les images

  1. Ouvre ce fichier dans Chrome, Edge ou Firefox (double-clic dessus suffit).
  2. Clic droit sur le cadre à exporter (bordure bleue en pointillés) → Inspecter.
  3. Dans l'inspecteur, l'élément survolé doit être sélectionné (surligné). Vérifie que c'est bien le <div id="og-frame"> (ou id="icon-180" / id="icon-512") qui est sélectionné, pas un enfant.
  4. Chrome/Edge : ouvre la palette de commandes avec Ctrl/Cmd+Shift+P, tape Capture node screenshot et valide. Firefox : clic droit sur l'élément dans l'inspecteur → Screenshot Node.
  5. Le fichier PNG téléchargé est exactement aux bonnes dimensions (pas de marge, pas de barre de défilement).
  6. Renomme et place les fichiers dans frontend/public/ : og-image.png (1200×630), apple-touch-icon.png (180×180), icon-512.png (512×512).

Note pour l'icône 512×512

L'aperçu ci-dessus est affiché en 200×200 pour tenir sur l'écran, mais l'élément #icon-512 ne fait pas 512×512 dans le DOM. Pour l'exporter à la bonne taille sans scroller, ouvre la console du navigateur (F12 → onglet Console) et colle :

document.getElementById('icon-512').style.width='512px'; document.getElementById('icon-512').style.height='512px';

Puis refais la manipulation « Capture node screenshot » / « Screenshot Node » sur cet élément. Le résultat sera un PNG 512×512 exact.
